# RivalsWaffle

WindUI-based script for Rivals — ESP (boxes, names, distance, health, skeleton, tracers, offscreen arrows, chams), silent aim via raycast namecall hook, camera aim, team check, config save/load.

## Execute

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/vrcdev/RivalsWaffle/main/loader.luau"))()
```

## Controls

- **Delete** — toggle menu
- **End** — unload
